# 8. חדרי ילדים

מדלגים אם אין ילדים. שואלים לכל חדר בנפרד.

סימון: **(בחירה אחת)** = radio, **(בחירה מרובה)** = checkbox. בלי סימון = שאלה פתוחה. בכל שאלה אפשר גם תשובה חופשית.

- מספר מיטות בחדר (בחירה אחת: אחת / שתיים / שלוש ומעלה)
- הכנת שיעורי בית (בחירה אחת: שולחן בחדר / בחלל משותף)
- אחסון בגדים (שאלה פתוחה)
- אחסון צעצועים (שאלה פתוחה)
- משחקים עם חברים (בחירה אחת: בחדרים / בחלל ציבורי / גם וגם)
- צבעים אהובים על הילדים (שאלה פתוחה)
- אחסון נוסף (שאלה פתוחה)
