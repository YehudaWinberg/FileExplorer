# 4. מטבח – פרוגרמה (הרגלי שימוש וצרכים)

סימון: **(בחירה אחת)** = radio, **(בחירה מרובה)** = checkbox. בלי סימון = שאלה פתוחה. בכל שאלה אפשר גם תשובה חופשית ([כללי השאלות](../SKILL.md)).

## אופי המטבח
- מטבח פתוח או סגור? (בחירה אחת: פתוח / סגור)
- כמה פעיל? (בחירה אחת: פעיל / פחות פעיל)
- בישול (בחירה אחת: מבשלים / אוכל מוכן / גם וגם)
- אפייה (בחירה אחת: ביתית / ממאפייה / גם וגם)
- אירוח במטבח (בחירה אחת: מעט / הרבה)
- כלים (בחירה אחת: רגילים / חד-פעמי / גם וגם)
- קניית מזון (בחירה אחת: שבועית / חודשית)

## ציוד
- גודל כיורים (שאלה פתוחה)
- תנורים (בחירה אחת: אחד / שניים / אחר)
- גודל כיריים (שאלה פתוחה)
- סוג כיריים (בחירה מרובה: גז / חשמל / אינדוקציה / אחר)
- מדיחי כלים (בחירה אחת: אחד / שניים / אין) ומייבשי כלים (בחירה אחת: כן / לא)
- שואב רובוטי או דייסון (בחירה מרובה: דייסון / רובוט / אף אחד)

## ישיבה
- בר / שולחן אוכל (בחירה מרובה: בר / שולחן אוכל)
- כמות סועדים בו-זמנית (שאלה פתוחה)
