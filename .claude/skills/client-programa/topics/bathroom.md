# 9. אמבטיה וכביסה

סימון: **(בחירה אחת)** = radio, **(בחירה מרובה)** = checkbox. בלי סימון = שאלה פתוחה. בכל שאלה אפשר גם תשובה חופשית.

- רחצה (בחירה מרובה: אמבטיה / מקלחון)
- ברזים וכיורים (שאלה פתוחה)
- תליית כביסה (בחירה מרובה: מרפסת שירות / בחדר / מייבש / אחר)
- מכונות כביסה וייבוש: מיקום מועדף (שאלה פתוחה)
- אחסון אביזרי אמבטיה (שאלה פתוחה)
- מגהץ וקרש גיהוץ (בחירה אחת: פתוח / סגור)
- אחסון כביסה (שאלה פתוחה)
