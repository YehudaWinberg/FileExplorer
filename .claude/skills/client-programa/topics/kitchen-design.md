# 5. מטבח – טופס הכנה לפגישת תכנון

פרטים טכניים. מתאים כשהלקוח מוכן להעמיק, או לפני פגישת תכנון מטבח.
לא לשאול שוב מה שכבר נענה ב-[kitchen.md](kitchen.md).

סימון: **(בחירה אחת)** = radio, **(בחירה מרובה)** = checkbox. בלי סימון = שאלה פתוחה. בכל שאלה אפשר גם תשובה חופשית ([כללי השאלות](../SKILL.md)).

## פרטים כלליים
- תאריך הפגישה
- שם הלקוח
- מיקום הפרויקט

## כללי
- סוג המטבח (בחירה אחת: ראשי / יחידת דיור / מטבחון)
- סוג בישול (בחירה אחת: קל / בינוני / כבד)
- מספר משתמשים קבועים במטבח
- דרישות מיוחדות (בחירה מרובה: בר מים / נישה / אחר)

## סגנון עיצובי
- סגנון מועדף (בחירה אחת: מודרני / כפרי / נקי / שילוב)
- צבעים מועדפים
- סוג חזיתות
- סוג ידיות (בחירה אחת: ידיות / אינטגרלי)
- משטח עבודה
- חיפוי קיר

## מבנה המטבח
- תצורה (בחירה אחת: קו אחד / ר"ש (L) / חצי אי (U) / אי)
- האם יש אי או דלפק (בחירה מרובה: אי / דלפק / אף אחד)
- גובה ארונות עליונים
- סידור כללי

## מוצרי חשמל
לכל פריט: האם יש / כמה / דגם או העדפה (שאלה פתוחה).
- מקרר
- תנור בילט-אין
- כיריים (בחירה מרובה: אינדוקציה / גז / הכנה לגז)
- מדיח
- מיקרוגל
- קולט אדים
- מקפיא

## פרזול ואחסון
- סגנון חלוקה
- מגירות פנימיות (לבקש תמונת דוגמה של חלוקה)
- ארון מזווה (גודל, ויטרינת כלי כסף בכניסה)
- מגירת תבלינים (רוחב)
- מגירת סירים
- פתרונות פינתיים (בחירה מרובה: קלפה / קרוסלה / אחר)
- בקשות נוספות

## תשתיות
- נקודות מים (בחירה אחת: קיימות / חדשות / גם וגם)
- מיקומי חשמל
- הערות לתשתיות

## הערות כלליות
- שאלה פתוחה
