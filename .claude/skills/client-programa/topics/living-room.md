# 6. סלון

סימון: **(בחירה אחת)** = radio, **(בחירה מרובה)** = checkbox. בלי סימון = שאלה פתוחה. בכל שאלה אפשר גם תשובה חופשית.

- אירוח (שאלה פתוחה: כמה אנשים, באיזו תדירות)
- הרגלי שימוש בסלון (בחירה מרובה: טלוויזיה / קריאה / משחקים / עבודה)
- ארון ספרים (בחירה אחת: כן / לא)
- הדלקת נרות (בחירה מרובה: שבת / חג / אחר / לא)
- ארונות אחסון (בחירה מרובה: מעילים / כלים / אחר)
- שירותי אורחים (בחירה אחת: כן / לא)
- כיור נטילת ידיים (בחירה אחת: כן / לא)
