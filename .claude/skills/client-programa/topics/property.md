# 2. הנכס

## מיקום
- איפה הנכס נמצא (עיר / שכונה)
- כתובת: רחוב ומספר בית

## סוג הנכס (בחירה אחת)
- דירה / בית / וילה

## מצב הפרויקט (בחירה מרובה, כי אפשר שיפוץ והרחבה יחד)
- נכס חדש
- יד שנייה
- שיפוץ
- הרחבה

## קומות
- כמה קומות יש? (בחירה אחת: קומה אחת / שתיים / שלוש ומעלה)
- **קומה אחת:** הכול נכנס בה, אין צורך בפירוט נוסף.
- **כמה קומות:** לכל קומה לשאול מה מספרה ומה הייעוד שלה (מגורים, שינה, אירוח, יחידת דיור, מרתף וכו').
