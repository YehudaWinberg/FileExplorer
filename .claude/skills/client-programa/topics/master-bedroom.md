# 7. חדר שינה הורים ויחידת הורים

סימון: **(בחירה אחת)** = radio, **(בחירה מרובה)** = checkbox. בלי סימון = שאלה פתוחה. בכל שאלה אפשר גם תשובה חופשית.

## חדר השינה
- גודל מיטות וגב מיטה (שאלה פתוחה)
- מיטות (בחירה אחת: זוגית אחת / שתי מיטות צמודות / שתי מיטות נפרדות)
- חדר ארונות (בחירה אחת: כן / לא / ארונות בחדר)
- פריטי לבוש ואחסון (שאלה פתוחה)

## יחידת הורים (חדר רחצה)
- רחצה (בחירה מרובה: אמבטיה / מקלחון)
- בידה (בחירה אחת: כן / לא)
