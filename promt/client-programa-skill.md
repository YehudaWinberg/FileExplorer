# Skill: client-programa – פרוגרמה ללקוחות לתכנון ועיצוב דירה

במסגרת קורס AI נדרש ליצור skill (לא חייב להיות קשור לפרויקט FileExplorer).

הסקיל ניתן ללקוח של מעצבת פנים, ובסוף מפיק פרוגרמה מסודרת על הלקוח.

## סדר הפעולה
1. הלקוח מתחיל שיחה.
2. שואלים אותו את כל השאלות לפי הסדר (שם פרטי, שם משפחה, ילדים ועוד).
3. עוברים על כל השאלות ומפרטים כמה שיותר.
4. התוצר: קובץ HTML בעברית, RTL, שמסכם את כל התהליך בצורה יפה.

## מבנה נדרש
- description ב-SKILL.md: סקיל לבניית פרוגרמה ללקוחות שמעוניינים בתכנון ועיצוב דירה.
- גוף הסקיל מפרט בקצרה; כל נושא (מטבח, סלון, חדרי ילדים ועוד) בקובץ נפרד בתת-תיקייה.
- המידע לא יושב בסקיל הראשי.

## נושאים שנמסרו
פרטי לקוח ומשפחה, הנכס, סגנון עיצוב, מטבח (פרוגרמה), טופס פגישת תכנון מטבח, סלון, חדר שינה הורים, חדרי ילדים, אמבטיה, כללי, דרישות מיוחדות ותקציב.
