# תרגיל 4 — הוספת ספירת שורות לקובצי TXT

## Context — הקשר

הפרויקט הוא FileExplorer קיים, המבוסס על React ו-TypeScript ומשתמש ב-File System Access API.

המערכת מציגה קבצים ותיקיות מתוך תיקייה שהמשתמש בחר.

השתלב בארכיטקטורה, ברכיבים ובדפוסי הקוד הקיימים. בחר את אופן המימוש בהתאם למבנה הפרויקט בפועל.

## Goal — מטרה

הוסף לרשימת הקבצים עמודה חדשה בשם "מספר שורות".

העמודה תציג את מספר השורות בכל קובץ מסוג TXT, כולל שורות ריקות.

## Expected Behavior — התנהגות מצופה

### הצגת העמודה

- העמודה "מספר שורות" תופיע לצד העמודות הקיימות ברשימת הקבצים.
- עבור קובצי TXT יוצג מספר השורות.
- עבור קבצים מסוגים אחרים ותיקיות יוצג המקף "—".
- הזיהוי של קובצי TXT אינו רגיש לאותיות גדולות וקטנות בסיומת.

### כללי ספירת השורות

- כל שורה נספרת, כולל שורות ריקות.
- קובץ ריק לחלוטין מכיל 0 שורות.
- קובץ המכיל טקסט ללא ירידת שורה מכיל שורה אחת.
- ירידת שורה בסוף הקובץ אינה מוסיפה שורה נוספת.
- יש לתמוך בסיומות שורה מסוג LF ו-CRLF.

### טעינה אסינכרונית

- רשימת הקבצים תוצג מבלי להמתין להשלמת ספירת השורות.
- בזמן חישוב מספר השורות יוצג חיווי טעינה מתאים בתא הרלוונטי.
- כאשר החישוב מסתיים, התא יתעדכן במספר השורות.
- כישלון בקריאת קובץ לא ימנע את הצגת שאר הקבצים. במקרה כזה יוצג חיווי שגיאה ברור במקום מספר.
- מעבר לתיקייה אחרת לא יגרום להצגת תוצאות ישנות השייכות לתיקייה הקודמת.

## Examples — תוצאות צפויות

| תוכן הקובץ | מספר שורות |
|---|---|
| קובץ ריק | 0 |
| `Hello` | 1 |
| `Hello\nWorld` | 2 |
| `Hello\n\nWorld` | 3 |
| `Hello\n` | 1 |
| `\n\n\n` | 3 |
| `Hello\r\nWorld` | 2 |

בדוגמאות, `\n` מייצג ירידת שורה מסוג LF ו-`\r\n` מייצג CRLF.
