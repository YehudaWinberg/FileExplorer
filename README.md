# סייר הקבצים (Windows File Browser)

אפליקציית Web בעברית (RTL) שמדמה את סייר הקבצים של Windows 11 וקוראת תיקיות וקבצים אמיתיים מהמחשב באמצעות File System Access API.
הפרויקט **לקריאה בלבד**: אין מחיקה, שינוי שם, העברה או כתיבה לדיסק, ואין Backend.

## דרישות
- Node.js 20 ומעלה
- Google Chrome או Microsoft Edge עדכני (File System Access API אינו נתמך ב-Firefox וב-Safari)

## הרצה
```bash
npm install
npm run dev        # פיתוח, בדרך כלל בכתובת http://localhost:5173
npm run typecheck  # בדיקת TypeScript
npm run lint       # oxlint
npm test           # בדיקות יחידה (Vitest)
npm run build      # בניית Production לתיקיית dist
npm run preview    # הרצת גרסת ה-Production
```

## ארכיטקטורה
```
src/
  lib/         לוגיקה ללא React: FileSystemAdapter, BrowserFileSystemAdapter (File System Access API),
               metadata (מידות תמונה ו-EXIF), models, utils (סוגי קבצים, פורמט, מיון)
  state/       reducer + Context: ניווט, היסטוריה, בחירה, מיון, עץ תיקיות (Lazy)
  components/  רכיבי UI, כולל DetailsPane (פרטי קובץ, תצוגה מקדימה, מידות, EXIF)
  styles/      tokens.css (כל משתני העיצוב) ו-app.css
```
src/lib אינו מייבא React (נאכף בכלל lint). כל הגישה לקבצים מתבצעת בדפדפן בלבד, לקריאה בלבד,
ללא Backend, ללא קריאות רשת וללא שמירה מתמשכת (ה-handles נשמרים בזיכרון בלבד).
תיקיות משנה נטענות רק בעת פתיחתן (Lazy Loading).

## מגבלות דפדפן
- הדפדפן אינו חושף נתיב Windows מלא; שורת הכתובת מציגה את שם התיקייה שנבחרה ואת המסלול בתוכה.
- אין גישה אוטומטית לתיקיות המערכת (שולחן עבודה, מסמכים וכו'). לחיצה על פריט כזה פותחת את חלון הבחירה של הדפדפן בתיקייה המתאימה, והמשתמש מאשר.
- תיקיות מסוימות (למשל שורש כונן או תיקיות מערכת) נחסמות על ידי הדפדפן.
- הדפדפן אינו מספק תאריך שינוי לתיקיות, ולכן העמודה ריקה עבורן.

## בדיקה ידנית מומלצת
1. פתיחת האפליקציה ב-Chrome/Edge: הממשק בעברית, הסרגל מימין, הרשימה במרכז, שורת הכתובת למעלה.
2. "בחירת תיקייה": בחירת תיקייה אמיתית ואישור. הקבצים מוצגים עם סוג, גודל ותאריך.
3. ביטול חלון הבחירה: לא מוצגת שגיאה.
4. הרחבה/צמצום תיקיות בעץ, ולחיצה על תיקייה בעץ.
5. לחיצה כפולה על תיקייה, ואז חזרה / קדימה / תיקיית אב / רענון.
6. מיון בכל עמודה (תיקיות תמיד ראשונות); בחירה בלחיצה, Ctrl ו-Shift; עדכון שורת המצב.
7. תיקייה ריקה: מוצגת ההודעה "התיקייה הזו ריקה".
8. פריטי שולחן עבודה/מסמכים/הורדות/תמונות: מעומעמים עד שניתנה גישה.
9. בחירת קובץ בודד: נפתחת חלונית פרטים. בחירת תמונה מציגה תצוגה מקדימה, מידות ונתוני EXIF (אם קיימים).
10. רענון הדף: לא נשמרות תיקיות או הרשאות, ויש לבחור תיקייה מחדש.
