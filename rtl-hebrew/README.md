# rtl-hebrew

Mod ל-Claude Code שמצייר שורות בעברית מימין לשמאל בטרמינל: בתשובות של Claude, בפרומפט שנשלח, ובשורת מראה מעל תיבת הקלט שמציגה את הטיוטה בזמן הקלדה.

## התקנה לפיתוח

```
claude --plugin-dir C:\FileExplorer\rtl-hebrew
```

ה-Mod נטען רק אחרי אישור "Turn on the mods Claude writes in this session?" אם הוא מתבקש.

## איך זה עובד

- שורה שיש בה עברית (U+0590 עד U+05FF) מצוירת ב-`Text dir="rtl"`.
- עטיפת השורות היא `Box` ברוחב `100%` (כשיש סימן `●` או `>` גוף ההודעה ממלא את השורה עם `flexGrow`, והסימן מוצב אחריו, כלומר בקצה הימני, פעם אחת בלבד), כדי ששורות העברית יתיישרו לקצה הימני של החלון.
- שורה בלי עברית עוברת ל-`next(e)` ללא שינוי. תשובה בלי שורת עברית בכלל מצוירת בידי המנוע.
- בלוקי קוד (` ``` `) נשארים LTR. fence שלא נסגר: עד סוף הטקסט הוא קוד.
- hook שנכשל מעביר ל-`next(e)`, כך שהתצוגה לא נשברת.
- לתיבת הקלט עצמה אין `dir` ב-API, ולכן יש שורת מראה (`AbovePrompt`). לא מוסיפים תווי כיוון לטיוטה או לפרומפט.

## מגבלות (v1)

- עיצוב בתוך שורת עברית (נשמר, כ-`Text` מקונן בתוך ה-`Text dir="rtl"` של השורה): `קוד` בצבע `permission` בלי backticks, **הדגשה**, *נטוי*, וקישור `[טקסט](url)` כטקסט עם קו תחתון (ה-url לא מוצג). סימנים שלא נסגרו נשארים כטקסט רגיל.
- לא מעוצב: טבלאות (שורת `| ... |` עם עברית מוצגת גולמית), `_נטוי_` עם קו תחתון, עיצוב מקונן בתוך עיצוב, תמונות. שאר השורות (בלי עברית) ובלוקי קוד מצוירים כ-markdown רגיל.
- בשורות עברית: כותרת (`##`) מוצגת מודגשת בלי `#`, סימן רשימה (`-`, `*`) הופך ל-`•`, סימן ציטוט (`>`) הופך ל-`│`, ורשימה ממוספרת נשארת כפי שהיא.
- טבלאות: שורת טבלה (`| ... |`) עם עברית מוצגת כפי שנכתבה, בלי יישור RTL של העמודות. זו מגבלה ב-v1.
- טרמינל שמסדר טקסט דו-כיווני בעצמו עשוי לצייר את ה-`Text` בדיוק כמו בלי `dir`. נדרשת בדיקה ידנית ב-Windows Terminal.
